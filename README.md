# Pesquisa: venda de sites nichada (Brasil, 21/11/2026)

Quem vende criação de site por nicho no Brasil: criativos, ganchos, ofertas, preços e players, a partir da Biblioteca de Anúncios da Meta.

- `index.html`: relatório (abrir no navegador)
- `01-pesquisa/dados`: anúncios minerados, análise, temas e transcrições
- `01-pesquisa/criativos`: folhas com o primeiro quadro dos criativos e recortes usados na galeria
- `scripts`: scripts que geraram tudo (`gerar.py` monta o `index.html`)
